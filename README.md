# PowerBI - Competitor Sales Analysis

## Overview
This project focuses on building a competitor sales analysis dashboard in Power BI using a fictional manufacturing company called Sintec and its competitors startingg from the data integration from multiple sources, data transformation, modeling, and then visualization.
### Aim: The report analyzes:
- Sales performance                                   - Revenue trends
- Market share                                        - Product growth
- Geographic performance                              - Competitor comparison
